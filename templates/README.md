# 카드 템플릿 디자인 규격 (디자이너 전달용)

## 카드 전체 구조 — 1080 × 1440 px (세로 3:4)

```
┌──────────────────────────┐ 0
│                          │
│   상단: 합격 기원 디자인    │  ← 디자인 이미지가 들어가는 영역
│      1080 × 740 px       │
│                          │
├──────────────────────────┤ 740
│  ┌────────────────────┐  │ 772
│  │ To. 사랑하는 우리 …  │  │
│  │                    │  │  ← 프로그램이 자동으로 그리는
│  │  (응원 메시지)       │  │    흰색 메시지 박스
│  │                    │  │    x 64 / y 772 / 952 × 572
│  │       From. 엄마·아빠가│  │
│  └────────────────────┘  │ 1344
│  2027학년도 국민대학교 논술고사 │ ← 행사명(자동)
└──────────────────────────┘ 1440
```

## 방식 A — 상단 이미지만 제작 (권장, `layout: 'top'`)

| 항목 | 규격 |
|---|---|
| 크기 | **1080 × 740 px** (같은 비율이면 2160 × 1480 도 가능) |
| 형식 | PNG 또는 JPG, 1장당 1MB 이하 권장 |
| 내용 | ‘합격 기원’ 메인 디자인 (문구·일러스트·캐릭터 등) |
| 주의 | 하단 740px 아래 영역은 프로그램이 채움 → 이미지 **아래쪽 끝 색**과 `config.js`의 `colors.bg`를 맞춰 주세요 |

## 방식 B — 카드 전체 이미지 제작 (`layout: 'full'`)

| 항목 | 규격 |
|---|---|
| 크기 | **1080 × 1440 px** |
| 비워 둘 곳 | 메시지 박스 영역 **x 64 ~ 1016, y 772 ~ 1344** 는 글씨가 들어가니 비워 두기 |
| 박스를 직접 디자인한 경우 | `config.js`에서 `drawBox: false` 로 설정 → 흰 박스 대신 디자인의 박스가 보임 |
| 행사명을 디자인에 넣은 경우 | 템플릿에 `showFooter: false` 추가 |

## 파일 이름 예시

```
templates/card-01.png   → 1번 디자인
templates/card-02.png   → 2번 디자인
templates/card-03.png   → 3번 디자인
```

파일명은 **영문·숫자·하이픈**만 사용해 주세요(한글·공백 X).

## 글씨 색 맞추기

`config.js` 의 각 템플릿 `colors` 에서 조정합니다.

| 키 | 위치 |
|---|---|
| `bg` | 카드 배경(하단 여백 포함) |
| `box`, `boxLine` | 메시지 박스 바탕색, 안쪽 테두리선 |
| `to`, `message`, `from` | To · 메시지 · From 글씨 색 |
| `footer` | 맨 아래 행사명 색 |
